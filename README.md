# Nexlogic - AI Recruitment Assistant (ARA)

A full-stack web application to help HR recruiters:
1. Find candidate profiles matching a job description.
2. Generate an AI hiring banner using the company's own logo and brand colors.
3. Generate a ready-to-use LinkedIn hiring post (text + hashtags + emojis).

## Project Structure

*   `frontend/`: React + Vite + Tailwind CSS application.
*   `backend/`: Python FastAPI + SQLAlchemy application.
